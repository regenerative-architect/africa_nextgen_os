# Roles and accountable review

| Role | Permitted actions |
|---|---|
| Viewer | Read public reviewed information and references |
| Contributor | Prepare drafts and private corrections |
| Analyst | Contributor actions and intervention stage evidence |
| Reviewer | Review claims, private corrections and observed outcomes |
| Publisher | Publish an approved revision, cancel and authorize configured relay |
| Governor | Administer human membership and perform governed actions subject to identity separation |
| Ingestion agent | Create draft candidates only |

Governors do not bypass the distinct-person rule: author ≠ reviewer ≠ publisher. Role grants cannot turn an ingestion bearer into a human; agent identity remains an immutable request capability. Keep ingestion credentials separate from human credentials. No AI runtime is bundled, and no agent endpoint can diagnose, allocate aid, rank people, accuse, pay or control physical systems.

Review covers source date, observation period, method, geographic applicability, contradictions, forecast assumptions, uncertainty, expiry, translation and disclosure risk. A human must not approve a high-stakes claim merely because its publisher is respected. Official-source mirroring has no ungated fast path in this deployment: authentication of official alerts has not been provisioned. It uses the same review gate until an explicitly authenticated official-mirror adapter is introduced.

Local feedback categories are correction, local context, service change, unsafe location, intervention already occurring and outdated information. Feedback is private until a reviewer makes a separate approved evidence revision. Acceptance of feedback never silently rewrites a canonical published claim. Review decisions retain audit events. Provide an accessible local complaint/referral channel through the implementing organization; the app does not invent phone numbers or emergency service capacity.

Public disclosure uses allowlists at every serialization boundary. Raw child records, routes, coordinates, admin-2 fields, contacts, member IDs, internal review notes and outcome narratives are excluded. Country/admin-1, temporal delay and declared small-sample suppression are conservative rules, not a universal anonymity guarantee. Free-text statements and linked primary reports need human disclosure review. Avoid retaining identifiable child information anywhere in this application.

Interface labels support English, French, Arabic, Portuguese and Swahili. Arabic uses right-to-left layout. Interface translations are provisional and visibly flagged; evidence stays in the source language. The system does not fabricate machine translations or regard translation as evidence verification. Additional languages can be added to the resource module without changing the canonical ontology.
